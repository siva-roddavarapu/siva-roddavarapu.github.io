# Freelance portfolio

Plain HTML/CSS/JS with no build step. Open `index.html` in a browser to preview it.

| File | What it is |
|---|---|
| `index.html` | Portfolio homepage: work, pricing, process, contact |
| `demos/restaurant.html` | Demo 1: restaurant landing page with menu tabs and a reservation form |
| `demos/clinic-booking.html` | Demo 2: appointment booking with doctors, dates and free/booked slots |
| `demos/dashboard.html` | Demo 3: sales admin dashboard with KPIs, chart, filterable table and dark mode |
| `GIGS.md` | Your private playbook (kept out of git because this repo is public) |

All demo businesses and data are fictional, and each demo says so in a banner.

## Put it online for free (GitHub Pages)

1. On GitHub, create a **public** repo named exactly **`siva-roddavarapu.github.io`**, empty with no README.
2. Push this folder to it (Claude can do this step).
3. In the repo, go to **Settings → Pages**, set Source to *Deploy from a branch*, choose Branch `main` and folder `/ (root)`, then Save.
4. After about 1 minute it's live at **https://siva-roddavarapu.github.io**.
